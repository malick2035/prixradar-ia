# Code de conduite

PrixRadar.IA est un projet ouvert au service de la sécurité alimentaire. Nous attendons de chaque participant :

- le respect de toutes les personnes, quels que soient leur genre, leur origine, leur langue, leur religion ou leur niveau d'études ;
- des échanges courtois et constructifs ;
- l'honnêteté sur les données : ne jamais présenter un chiffre comme plus certain qu'il ne l'est ;
- le refus de tout usage du projet pour tromper, escroquer ou spéculer au détriment des ménages.

Les comportements contraires peuvent entraîner l'exclusion du projet. Signalement : data.malick9@gmail.com.
