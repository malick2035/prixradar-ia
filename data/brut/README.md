# Données brutes du PAM

Ces fichiers ne sont pas versionnés (taille). Pour recalculer les résultats, téléchargez sur https://data.humdata.org les fichiers « Food Prices » du PAM pour le Bénin, le Togo, le Niger et le Sénégal, et placez-les ici sous les noms :

- wfp_food_prices_ben.csv
- wfp_food_prices_tgo.csv
- wfp_food_prices_ner.csv
- wfp_food_prices_sen.csv

Puis lancez `python scripts/preparer_donnees.py` depuis la racine du dépôt.
