# Sources et licences

## Données

**Programme alimentaire mondial (PAM / WFP)**, base de données des prix alimentaires, publiée sur la plateforme HDX (Humanitarian Data Exchange) des Nations unies :
« Benin - Food Prices », « Togo - Food Prices », « Niger - Food Prices », « Senegal - Food Prices ».

- **Licence : Creative Commons Attribution pour les organisations intergouvernementales (CC BY-IGO).** La réutilisation et la redistribution sont autorisées, à condition de citer la source.
- Le PAM compile ces prix à partir de plusieurs sources nationales et internationales (indiquées sur chaque page HDX).
- **Citation recommandée** : « Source : Programme alimentaire mondial (PAM), base de données des prix alimentaires, via HDX (data.humdata.org), licence CC BY-IGO. Traitement : PrixRadar.IA. »
- Les données nettoyées de ce dépôt sont un travail dérivé : valeurs aberrantes écartées, noms harmonisés (voir [docs/03_methodologie.md](docs/03_methodologie.md)).

**SIM-Agricole (CT-SAGSA, Ministère de l'Agriculture, de l'Élevage et de la Pêche du Bénin)** : non intégré à ce jour. Son utilisation fera l'objet d'une demande d'autorisation et d'une citation systématique.
