# Gouvernance

- **Porteur et mainteneur principal** : Malick OKASSE.
- **Décisions** : les changements de méthode sont proposés dans une « issue », documentés, testés, puis annoncés dans le [CHANGELOG](CHANGELOG.md) avec leur effet sur les chiffres.
- **Transparence** : toute erreur découverte dans des chiffres déjà publiés fait l'objet d'un erratum public.
- **Continuité** : objectif d'au moins deux personnes capables de maintenir le projet d'ici la fin du pilote ; procédures documentées dans le [guide de construction](docs/) et le code.
- **Partenaires** : les partenaires (données, diffusion, financement) sont consultés sur les évolutions qui les concernent ; aucun partenaire ne peut imposer la modification d'un résultat.
- **Évolution** : à la création de la structure juridique, la gouvernance sera inscrite dans ses statuts (comité d'orientation incluant des représentantes et représentants des commerçants).
